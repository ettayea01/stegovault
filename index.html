How it works — and its honest limits

Image mode (LSB): the message is written into the least-significant bits of the image's red, green and blue values — changes far too small for any eye to see. The output is always a PNG, because JPEG compression would scramble those bits and destroy the message.

PDF / any-file mode (append): the message is attached in a small marked block at the very end of the file, after its normal end. PDF readers, image viewers and players ignore trailing bytes, so the carrier still opens and works exactly as before.

Encryption: with a password, the message is sealed with AES-256-GCM (key derived via PBKDF2-SHA-256, 100,000 rounds, fresh random salt and IV every time) before it is hidden. Without the password the hidden bytes are unreadable noise; a wrong password simply fails to open them.

Limits: an image can only hide about 3 bits per pixel, so very long messages need big images — the app tells you the capacity before you download. Appended blocks survive only while the file's bytes stay untouched: re-saving, converting or recompressing the carrier removes them.

StegoVault runs entirely in your browser. Nothing is uploaded anywhere — files, messages and passwords never leave this page.
